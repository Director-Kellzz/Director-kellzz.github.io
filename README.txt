# Dir. Kellzz Portfolio — Starter

Open `index.html` in a browser to preview the site.

## What to replace
- Showreel placeholder: replace with your YouTube embed/link.
- Each category's "Watch films" link can point to a YouTube playlist or individual film.
- Replace YOURNUMBER, YOUREMAIL@example.com and YOURINSTAGRAM.
- Replace the About text with your actual bio.
- Replace project placeholders with your own stills/thumbnails.

## Publishing for free
This folder is ready for GitHub Pages. Create a GitHub repository, upload these files, then enable Pages from the repository's Settings > Pages. Your free site will use a github.io address until you connect a custom domain.
